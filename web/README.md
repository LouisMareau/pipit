# Pipit web app

The installable app (PWA) that runs the emulator in the browser, on phones and on
the desktop.

```
src/
  main.ts        entry point: registers the service worker and starts the app
  types.ts       worker messages, key bits, settings
  ui/            everything on screen: library, player, canvas, touch controls, styles
  features/      app-level features: save export/import, screenshots
  platform/      browser plumbing: emulator worker, audio output, input, IndexedDB
public/
  audio-worklet.js   AudioWorklet processor (plain JS; loaded by URL)
  icons/             app icons (PNGs generated by scripts/make-icons.py)
scripts/
  build-wasm.mjs     builds crates/wasm and generates bindings into build/wasm
```

## Running

```bash
npm install
npm run dev      # builds the WASM core, then serves with hot reload
npm run build    # production build into build/web
```

`npm run wasm` needs `wasm-bindgen-cli` at the same version as the `wasm-bindgen`
crate in `Cargo.lock`:

```bash
cargo install wasm-bindgen-cli --version <version>
```

## How it fits together

- The emulator core runs in a Web Worker (`platform/worker.ts`). It paces itself to
  59.73 Hz, posts each frame's pixels and audio to the UI thread, and reports save
  data whenever the game writes its backup memory.
- Audio goes to an `AudioWorklet` with a small ring buffer that resamples 32768 Hz
  to the device rate.
- ROMs, saves and settings live in IndexedDB. Nothing leaves the device.
