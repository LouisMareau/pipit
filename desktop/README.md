# Desktop app

A [Tauri](https://tauri.app) window around the web app. The emulator, storage,
input and audio all run inside the system webview exactly as in the browser; this
folder only adds the native window, the app icon and installers.

```
package.json          scripts: `npm run dev`, `npm run build` (installers in build/target/release/bundle)
src-tauri/            the Rust shell (its own Cargo project, excluded from the workspace)
  tauri.conf.json     window, bundle and frontend settings — points at ../../build/web
  icons/              generated by scripts/make-icons.py
```

## Building

Requirements: the usual Rust toolchain, Node.js, and on Windows the WebView2
runtime (preinstalled on Windows 10/11). On Linux, Tauri needs `webkit2gtk`.

```bash
cd desktop
npm install
npm run build       # builds the web app first, then the native app + installers
```

`npm run dev` opens a window on the Vite dev server with hot reload.
